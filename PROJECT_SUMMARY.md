# Мультибанк - Краткое описание проекта

## Что это?

Мультибанк - это веб-приложение для агрегации финансовых данных из разных банков в едином интерфейсе. Пользователи могут видеть все свои счета, карты и транзакции в одном месте, получать персональные рекомендации и использовать ИИ-помощника для управления финансами.

## Основные возможности

✅ **Регистрация и авторизация** - безопасная система входа с JWT токенами

✅ **Агрегация счетов и карт** - подключение нескольких банков через OAuth 2.0

✅ **Просмотр транзакций** - все транзакции в одном месте с фильтрами

✅ **Предложения банков** - поиск интересных предложений от всех подключенных банков

✅ **ИИ-помощник** (премиум) - анализ трат, рекомендации по оптимизации и кэшбэку

✅ **Профиль и настройки** - управление подключениями, темой и языком

## Технологии

### Backend
- Node.js + Express
- SQLite база данных
- JWT аутентификация
- OAuth 2.0 интеграция
- Axios для банковских API

### Frontend
- React
- React Router
- Axios
- CSS (с поддержкой темной темы)

## Быстрый старт

1. **Установка зависимостей:**
   ```bash
   npm run install-all
   ```

2. **Настройка .env файла:**
   Создайте `.env` файл с настройками (см. `docs/INSTALLATION.md`)

3. **Запуск:**
   ```bash
   npm run dev
   ```

4. **Откройте браузер:**
   http://localhost:3000

## Монетизация

- Базовый функционал (агрегация) - бесплатно
- ИИ-помощник и расширенная аналитика - платная подписка

## Безопасность

- Пароли хешируются с bcrypt
- JWT токены в HTTP-only cookies
- OAuth 2.0 для подключения банков
- Валидация всех входных данных
- Защита от SQL injection
