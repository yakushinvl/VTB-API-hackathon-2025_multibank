## Использование

### Запуск через npm:
```bash
npm run dev
```

### Запуск через node:
```bash
node server/start.js
# или
npm run start:file
```

### Подключение банка:
1. Перейдите в Профиль
2. Нажмите "Подключить" у нужного банка
3. Авторизуйтесь в банке
4. Банк будет автоматически подключен

### Активация подписки:
1. Перейдите в раздел "Помощник"
2. Нажмите "Оформить подписку"
3. Подписка активируется автоматически
