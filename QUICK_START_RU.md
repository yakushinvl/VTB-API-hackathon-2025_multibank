# Быстрый старт - Мультибанк

## 📋 Что нужно для запуска

1. **Node.js** версии 18 или выше ([скачать](https://nodejs.org/))
2. **npm** (устанавливается вместе с Node.js)
3. **Git** (опционально, для клонирования)

## 🚀 Установка и запуск

### Шаг 1: Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm run install-all
```

Эта команда установит все зависимости для backend и frontend.

### Шаг 2: Создание файла настроек

Создайте файл `.env` в корне проекта со следующим содержимым:

```env
PORT=5000
JWT_SECRET=ваш-секретный-ключ-измените-на-свой
NODE_ENV=development
CLIENT_URL=http://localhost:3000
```

**Важно:** Замените `ваш-секретный-ключ-измените-на-свой` на случайную строку (например, сгенерируйте через `openssl rand -hex 32`)

### Шаг 3: Запуск приложения

Выполните команду:

```bash
npm run dev
```

Эта команда запустит:
- **Backend сервер** на http://localhost:5000
- **Frontend приложение** на http://localhost:3000

### Шаг 4: Откройте браузер

Перейдите по адресу: **http://localhost:3000**

## 🎯 Первые шаги в приложении

1. **Зарегистрируйтесь** - создайте новый аккаунт
2. **Войдите** в систему
3. **Перейдите в профиль** - нажмите на аватар в правом верхнем углу
4. **Подключите банки** - в разделе "Доступные банки" нажмите "Подключить"
5. **Синхронизируйте данные** - после подключения банка данные синхронизируются автоматически

## 📱 Основные страницы

- **Главная** (`/`) - просмотр всех счетов и карт
- **Транзакции** (`/transactions`) - все транзакции с фильтрами
- **Предложения** (`/offers`) - предложения от банков
- **Помощник** (`/assistant`) - ИИ-анализ (требует подписку)
- **Профиль** (`/profile`) - настройки и управление

## 🔧 Решение проблем

### Ошибка: "Cannot find module"

**Решение:** Убедитесь, что выполнили `npm run install-all`

### Ошибка: "Port 5000 already in use"

**Решение:** Измените порт в `.env` файле или остановите процесс, использующий порт 5000

### Ошибка: "Cannot connect to API"

**Решение:** 
- Убедитесь, что backend запущен (проверьте терминал)
- Проверьте, что порт 5000 свободен
- Проверьте настройки в `.env` файле

### База данных не создается

**Решение:** Убедитесь, что у приложения есть права на запись в папку проекта

## 🌐 Развертывание на GitHub Pages

### Подготовка

1. Соберите frontend:
   ```bash
   cd client
   npm run build
   cd ..
   ```

2. Настройте API URL в `client/src/services/api.js`:
   ```javascript
   baseURL: 'https://ваш-production-api.com/api'
   ```

3. Загрузите папку `client/build` в GitHub Pages

### Альтернатива: Использование GitHub Actions

См. подробную инструкцию в `docs/INSTALLATION.md`

## 💡 Полезные команды

```bash
# Запуск только backend
npm run server

# Запуск только frontend
npm run client

# Сборка для production
npm run build

# Установка всех зависимостей
npm run install-all
```

## 🔐 Безопасность

⚠️ **Важно для production:**

1. Измените `JWT_SECRET` на случайную строку
2. Установите `NODE_ENV=production`
3. Настройте HTTPS
4. Используйте надежные пароли для БД (если используете PostgreSQL/MySQL)
5. Настройте rate limiting
6. Включите логирование

## 📞 Поддержка

При возникновении проблем:

1. Проверьте логи в терминале
2. Проверьте консоль браузера (F12)
3. Убедитесь, что все зависимости установлены
4. Проверьте версию Node.js: `node --version` (должна быть 18+)
