# Быстрый старт FinAggregator

## Шаг 1: Подготовка

1. Убедитесь, что у вас установлены Docker и Docker Compose
2. Клонируйте репозиторий (если нужно)

## Шаг 2: Настройка

1. Создайте файл `.env` в корне проекта на основе `.env.example`
2. Заполните необходимые переменные:
   - `DATABASE_URL` - URL базы данных (по умолчанию используется из docker-compose)
   - `OPENAI_API_KEY` - API ключ OpenAI (опционально, для ИИ ассистента)
   - Настройки банковских API (VBANK_API_URL, VBANK_CLIENT_ID, VBANK_CLIENT_SECRET и т.д.)
   - `JWT_SECRET_KEY` - Секретный ключ для JWT токенов

## Шаг 3: Запуск

```bash
docker-compose up -d
```

Это запустит:
- PostgreSQL (порт 5432)
- Redis (порт 6379)
- Backend API (порт 8000)
- Frontend (порт 3000)

## Шаг 4: Проверка

1. Откройте http://localhost:3000 в браузере
2. Зарегистрируйте нового пользователя
3. Войдите в систему
4. Подключите банк (например, VBank с client_id team200-1)
5. Синхронизируйте данные

## Шаг 5: Использование

### Подключение банка

1. Перейдите на страницу "Счета"
2. Нажмите "Подключить банк"
3. Выберите банк из списка
4. Введите client_id (например, team200-1)
5. Нажмите "Подключить"
6. Нажмите "Синхронизировать" для получения данных

### Просмотр транзакций

1. Перейдите на страницу "Транзакции"
2. Все транзакции со всех счетов будут отображены
3. Используйте фильтры для поиска

### ИИ ассистент (Premium)

1. Перейдите на страницу "Подписка"
2. Перейдите на Premium план
3. Откройте страницу "ИИ Ассистент"
4. Задайте вопросы о ваших финансах

## Устранение неполадок

### Backend не запускается

- Проверьте, что порт 8000 свободен
- Проверьте логи: `docker-compose logs backend`
- Убедитесь, что база данных запущена

### Frontend не запускается

- Проверьте, что порт 3000 свободен
- Проверьте логи: `docker-compose logs frontend`
- Убедитесь, что backend запущен

### Не могу подключить банк

- Проверьте правильность URL банка в `.env`
- Проверьте правильность client_id и client_secret
- Проверьте логи backend для деталей ошибок

### ИИ ассистент не работает

- Убедитесь, что OPENAI_API_KEY установлен в `.env`
- Проверьте, что у вас активна Premium подписка
- Проверьте логи backend для ошибок API

## Остановка

```bash
docker-compose down
```

Для удаления данных:

```bash
docker-compose down -v
```
