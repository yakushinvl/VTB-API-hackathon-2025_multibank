# FinAggregator - Решение для хакатона ВТБ HackAPI 2025

## Описание решения

FinAggregator - это единая платформа для управления всеми банковскими счетами, которая агрегирует данные из различных банков через Open Banking API. Решение решает проблему фрагментации финансовой картины пользователя и предоставляет единый интерфейс для управления финансами.

## Ключевые возможности

### 1. Агрегация счетов
- Подключение счетов из разных банков (VBank, ABank, SBank)
- Автоматическая синхронизация данных
- Категоризация счетов: дебетовые, накопительные, вклады, кредитные
- Единый интерфейс для просмотра всех счетов

### 2. Единая история трат
- Объединение транзакций со всех счетов
- Автоматическая категоризация транзакций
- Фильтрация и поиск по транзакциям
- Визуализация расходов по категориям

### 3. Управление финансами
- Просмотр балансов всех счетов
- Аналитика доходов и расходов
- Визуализация трат (графики и диаграммы)
- Сводная информация по финансам

### 4. Рекомендации продуктов
- Анализ текущих продуктов пользователя
- Подбор лучших предложений от других банков
- Сравнение условий (процентные ставки, кэшбэк)
- Отображение продуктов, которых еще нет у пользователя

### 5. ИИ ассистент (Premium)
- Анализ трат и паттернов расходов
- Персонализированные рекомендации по оптимизации
- Советы по выбору банковских продуктов
- Помощник по выбору кэшбэка
- Чат с ИИ для получения финансовых советов

## Технологический стек

### Backend
- **FastAPI** - современный веб-фреймворк для Python
- **PostgreSQL** - основная база данных
- **Redis** - кэширование (готово к использованию)
- **SQLAlchemy** - ORM для работы с БД
- **OpenAI API** - ИИ ассистент для анализа трат
- **JWT** - аутентификация и авторизация

### Frontend
- **React** + **TypeScript** - пользовательский интерфейс
- **Tailwind CSS** - стилизация
- **React Query** - управление состоянием и кэширование
- **Recharts** - визуализация данных
- **Axios** - HTTP клиент

### Инфраструктура
- **Docker** - контейнеризация
- **Docker Compose** - оркестрация сервисов

## Монетизация

### Бесплатный план
- Агрегация счетов из всех банков
- Единая история трат
- Базовая аналитика и визуализация
- Рекомендации продуктов (базовые)

### Premium план (999₽/мес)
- Все функции бесплатного плана
- ИИ ассистент для анализа трат
- Персонализированные рекомендации
- Помощник по выбору кэшбэка
- Продвинутая аналитика

## Масштабируемость

### Архитектура
- Модульная структура для легкого добавления новых банков
- Адаптеры для каждого банка (паттерн Adapter)
- Готовность к микросервисной архитектуре
- Асинхронная обработка запросов

### Добавление нового банка
1. Создать новый адаптер в `bank_adapter.py`
2. Добавить банк в базу данных
3. Настроить параметры в `.env`
4. Готово к использованию

### Локализация
- Готовность к добавлению новых языков
- Все тексты вынесены в отдельные компоненты
- Поддержка интернационализации (i18n) может быть легко добавлена

## Безопасность

- JWT токены для аутентификации
- Хеширование паролей (bcrypt)
- Валидация данных через Pydantic
- CORS настройки
- Проверка прав доступа к данным пользователя
- Безопасное хранение секретов в переменных окружения

## Использование Open Banking API

Решение полностью использует открытые банковские API:
- Аутентификация через OAuth2
- Запрос согласия (consent) на доступ к данным
- Получение счетов через `/accounts`
- Получение транзакций через `/transactions`
- Получение балансов через `/balances`
- Получение продуктов через `/products`

## Демонстрация решения

### Основные экраны:
1. **Главная страница** - обзор финансов, графики трат
2. **Счета** - управление счетами, подключение банков
3. **Транзакции** - история всех транзакций
4. **Продукты** - рекомендации банковских продуктов
5. **ИИ ассистент** - анализ трат и рекомендации (Premium)
6. **Подписка** - управление подпиской

### Пользовательский сценарий:
1. Регистрация и вход
2. Подключение банка (например, VBank с client_id team200-1)
3. Синхронизация счетов и транзакций
4. Просмотр агрегированных данных
5. Анализ трат через ИИ ассистент (Premium)
6. Получение рекомендаций по продуктам

## Технические детали

### API Endpoints:
- `/api/v1/auth/*` - аутентификация
- `/api/v1/accounts/*` - управление счетами
- `/api/v1/transactions/*` - транзакции
- `/api/v1/banks/*` - подключение банков
- `/api/v1/products/*` - рекомендации продуктов
- `/api/v1/ai/*` - ИИ ассистент (Premium)
- `/api/v1/subscription/*` - управление подпиской

### База данных:
- PostgreSQL с таблицами: users, banks, bank_connections, accounts, transactions, product_recommendations, ai_chat_messages

### Интеграция с банками:
- Адаптеры для VBank, ABank, SBank
- Автоматическое получение согласия
- Синхронизация данных
- Обработка ошибок
